# Служба и расписание снятия просроченных правил

Здесь два файла настройки systemd — менеджера служб Linux. Они позволяют
снимать из установленного фильтра C2-правила, срок которых закончился.
Например, правило до 9 декабря исключается при проверке срока 9 декабря UTC.

- `dns-blocklists-expiry.service` запускает `scripts/ru/expire_filter.py`:
  скрипт обновляет установленный фильтр и его кэш, проверяет DNS после
  перезапуска и восстанавливает прежние копии при ошибке.
- `dns-blocklists-expiry.timer` задаёт расписание: ежедневно в 00:00 UTC
  и через две минуты после загрузки сервера.

Файлы автоматически не устанавливаются. Перед установкой нужно сверить пути,
ID фильтра, имя службы AdGuard и DNS-порт. Порядок подключения и проверки:
[REGIONAL_COVERAGE.md](../docs/REGIONAL_COVERAGE.md#срок-на-установленном-сервере).
