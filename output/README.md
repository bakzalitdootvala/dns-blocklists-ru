# Готовые списки после сборки

Здесь лежат результаты сборки. Для нашего AdGuard нужен один файл:
`adguard/combined.txt` — в нём уже объединены домены, исключения и IP-правила.
В `threat-intel/` лежат проверенные IP-наборы, которые сборщик включает в этот фильтр.

| Каталог | Назначение | Кто создаёт/читает |
|---|---|---|
| [adguard/](adguard/README.md) | Наш combined.txt, региональные правила и манифест | pipeline.py; AdGuard и check_artifact.py |
| [threat-intel/](threat-intel/README.md) | Подготовленные IP/CIDR и сведения об источниках | threat_intel.py; ip_inputs.py |

Для нашего DNS подключается `adguard/combined.txt`. Файлы в `adguard/` и
`threat-intel/` генерируются: ручная правка не воспроизводится при следующей сборке.
Меняйте источники/региональный каталог и запускайте проверки.
Локальные README описывают назначение форматов.

Навигация: [родительский каталог](../README.md) · [глоссарий](../docs/GLOSSARY.md).
