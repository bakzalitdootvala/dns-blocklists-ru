# Единый фильтр AdGuard Home

Здесь лежит `combined.txt` — готовый файл, который AdGuard читает для блокировки
доменов и IP в DNS-ответах. Например, рекламное имя или адрес из Spamhaus
совпадает с правилом, и AdGuard возвращает ответ блокировки.

Файл создаёт `scripts/ru/pipeline.py build` из доменных списков,
региональных записей и проверенных IP-наборов `output/threat-intel/`.

| Файл | Назначение |
|---|---|
| `combined.txt` | Именно этот файл подключается в AdGuard: содержит запреты доменов/IP, исключения и регулярные выражения (regex) для сетей |
| `manifest.json` | Описание сборки: откуда взяты данные, когда и сколько правил получилось. Наш код сверяет по нему SHA256 combined.txt; сам AdGuard его не читает |
| `ru-cis.txt` | Региональная часть, уже включённая в combined.txt, для отдельного просмотра |
| `upstream-ip-observations.txt` | Справочный список IP, найденных внутри доменных списков Mullvad. Записи из этого файла не добавляются в блокировки |

AdGuard читает combined.txt, а не manifest.json. Проверить соответствие файлов:
`python3 scripts/ru/check_artifact.py` из корня. Проверка DNS-поведения выполняется
отдельным `scripts/ru/test_ip_response.py` с настоящим AdGuard.

Даже если имя не попало в доменные запреты, адрес из сетевого списка может
вызвать блокировку ответа. Один regex (регулярное выражение) описывает сеть
без перечисления всех адресов. Точное разрешающее исключение AdGuard позволяет
сохранить ответ для указанного имени.
Ручное изменение combined.txt нарушает соответствие манифесту и будет затёрто сборкой.
В конце файла временные C2-правила обрамлены комментариями `Regional report`
и `End regional report`. В manifest `recent_reports` описывает их происхождение
и сроки, `regional_new_direct_names` — имена, для которых наша таблица добавила
прямую блокировку относительно тех же глобальных входов. Это не процент
защиты и не учёт блокировки по CNAME или IP. Счётчики считают строки правил.
Серверный expire_filter.py меняет установленную копию по сроку; её SHA256 после
такого изменения отличается от исходного выпуска в репозитории.
Изменения вносите в `regional/ru-cis/` или источники; сохраняйте уведомления лицензий.
