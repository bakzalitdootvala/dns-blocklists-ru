# Профиль категорий

Подключаемый файл `output/adguard/combined.txt` включает четыре категории:

| Категория | Содержимое | Включена |
|---|---|---|
| `adblock` | Реклама | Да |
| `privacy` | Трекеры и аналитика | Да |
| `malware` | Вредоносная инфраструктура, phishing и scam из выбранных источников | Да |
| `gambling` | Азартные игры и букмекерские сайты | Да |
| `adult` | Блокировка по тематике взрослого контента | Нет |
| `social` | Блокировка социальных сетей как категории | Нет |

Отключённая категория не является глобальным разрешающим правилом.
Реклама на сайте для взрослых и вредоносный домен, распространяемый в соцсети,
могут блокироваться по своей собственной категории.

Контрольные обычные, взрослые и социальные домены перечислены
в `config/controls.json`. Их блокировка останавливает выпуск.

Внутренние DNS-адреса Mullvad из оригинального проекта относятся к сети
Mullvad VPN. Для данного форка используется URL файла фильтра, указанный
в README; собственные DNS-адреса Mullvad на VPS не создаются.
