# Программы сборки и проверки списков

Здесь находятся программы, которые скачивают списки, собирают фильтр и проверяют
результат. Исполняемый код находится в [ru/](ru/README.md).

Корневой `build` запускает загрузку и проверку источников, затем сборку
`output/adguard/combined.txt`. Например, `ru/pipeline.py` объединяет доменные
списки с `regional/ru-cis/`, а `ru/test_ip_response.py` проверяет результат
на отдельном AdGuard. Все модули и их роли перечислены в README каталога ru/.

Команды и зависимости: [BUILDING.md](../BUILDING.md). Скрипты загрузки обращаются
в интернет, живые проверки запускают временные процессы и убирают их после работы.

Навигация: [родительский каталог](../README.md) · [глоссарий](../docs/GLOSSARY.md).
