# Собственные региональные дополнения

Здесь находятся наши дополнения для России и СНГ к готовым глобальным спискам.
Например, можно добавить конкретный рекламный домен или исключение для ошибочно
заблокированного сайта. Данные лежат в [ru-cis/](ru-cis/README.md);
страна, язык и доменная зона сами по себе не являются причиной блокировки.

`pipeline.py` читает таблицы каталога при сборке, проверяет категорию, область
совпадения, ссылку на доказательство и актуальное подтверждение malware.
Результат включается в `output/adguard/combined.txt` и отдельно виден в ru-cis.txt.
Для новой региональной подборки нужен такой же проверяемый реестр и явное
подключение в сборщик; одного создания подкаталога недостаточно.

Навигация: [родительский каталог](../README.md) · [глоссарий](../docs/GLOSSARY.md).
