# Документация профиля и сборки

Этот каталог объясняет термины, происхождение данных и подтверждённые проверки.
Если неизвестно значение DNS, CIDR, manifest или workflow, начните с глоссария.

- [GLOSSARY.md](GLOSSARY.md) — определения с примерами и привязкой к файлам проекта.
- [SOURCES.md](SOURCES.md) — используемые и исключённые источники, лицензии,
  ограничения актуальности и защита общих доменных платформ.
- [REGIONAL_COVERAGE.md](REGIONAL_COVERAGE.md) — дополнения по странам, пробелы и снятие истёкших C2 на сервере.
- [VERIFICATION.md](VERIFICATION.md) — проведённые проверки и границы их результата.

Команды разработки находятся в [BUILDING.md](../BUILDING.md), описание выбранных
категорий — в [COMBINATIONS.md](../COMBINATIONS.md). Отчёт о проверке обновляется
только после фактического прогона; наличие теста не доказывает успешного результата.
Новые термины из кода и обсуждения добавляйте в глоссарий с конкретным примером.

Навигация: [родительский каталог](../README.md) · [глоссарий](GLOSSARY.md).
