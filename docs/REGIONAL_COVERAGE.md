# Что добавляет региональная часть

Региональная часть закрывает конкретные рекламные сервисы, счётчики, азартные
игры и командные серверы вредоносных программ, найденные при исследовании РФ
и СНГ. Каждый запрет имеет источник; число строк не означает процент защиты.

В domains.csv — 64 записи, в recent-threats.json — 20 точных имён и 24 IP
Arra Ghouls. Общее число учитывает и записи, которые уже закрывает глобальная
база. `manifest.json` перечисляет дополнительную прямую блокировку имён в
`regional_new_direct_names`. CNAME (другое имя в DNS-ответе) и IP могут блокироваться
базой даже без прямого правила; для оценки прироста нужны живые запросы.

## Что проверено по странам

Перечень ниже задаёт область исследования, а не юридический состав СНГ.
Дата проверки источников: 9 ноября 2026. Связь с регионом означает аудиторию
сервиса или страну жертв, а не местонахождение сервера.

| Страна | Основание и применяемое дополнение | Граница результата |
|---|---|---|
| Россия | Метрика, Mail.ru, Soloway, Segmento и рекламные платформы; свежие C2 Arra Ghouls | Точные служебные hostname; поиск, почта, вход и обычные CDN не запрещаются как категории |
| Беларусь | Метрика; C2 Arra Ghouls по первичному отчёту Securelist | Betera уже есть в глобальной базе; AdGuard BY-секция преимущественно браузерная |
| Казахстан | `c.zero.kz` — счётчик ZERO; Метрика | `zero.kz` остаётся обычным контрольным сайтом; OLIMPBET уже покрыт |
| Узбекистан | Метрика; исследованы AdBozor и Digital Caramel | Выделенные hostname AdBozor не подтверждены; весь корпоративный сайт не запрещается |
| Кыргызстан | Точное имя Метрики `mc.yandex.kg` | Свежие отдельные местные C2 и рекламные hostname не подтверждены |
| Армения | Метрика; исследованы PRADIX, Media Systems, Digital Caramel | Новые выделенные адреса не подтверждены; мартовские IoC не активируются по возрасту статьи |
| Азербайджан | Метрика; `topaz.az` — оператор спортивных ставок | CERT Blacklist содержит общие сервисы и старые обнаружения, целиком не импортируется |
| Таджикистан | `mc.yandex.tj`; исходная база содержит `adv.topvideo.tj` | Исторический TAG-110 не выдаётся за свежий список IP |
| Туркменистан | `mc.yandex.tm` | Нет подтверждённого свежего локального feed; одно имя Метрики не означает полного национального покрытия |
| Молдова | Метрика; `7777.md` — лотерея/ставки | Браузерные правила для СМИ не превращаются в запрет самих СМИ |

Weborama и Hybrid международные; их рекламные hostname не считаются российскими
по происхождению. Дополнительные адреса Метрики за пределами СНГ относятся к тому
же сервису и не увеличивают число исследованных стран.

Обычные сайты девяти стран перечислены в [ordinary-sites.json](../regional/ru-cis/ordinary-sites.json):
банки, госпорталы, вход, торговые площадки, СМИ. Проверяется DNS A/AAAA;
это не проверка банковского платежа, входа в аккаунт или всех ресурсов страницы.

## Как принимается находка

Проверить первичный источник назначения, точное имя и область действия.
Сопоставить с глобальной базой и CNAME, добавить источник в domains.csv либо
recent-threats.json, пересобрать и проверить файл на отдельном AdGuard.
Один успешный DNS-ответ не подтверждает рекламное назначение домена.
Рекламные правила не получают IP просто путём DNS-разрешения имени.

RU AdList и браузерные секции AdGuard используются для исследования: условия
`$third-party`, `$domain`, URL-пути и CSS нельзя удалить и назвать результат DNS-фильтром.
Google providers.csv — справочник поставщиков рекламы, не готовый blacklist.
Корпоративные сайты, общие хостинги и взрослый контент целиком не импортируются.

Свежий первичный отчёт допускает точный C2 на 30 суток от публикации. Если
last_seen неизвестен, он остаётся null. Для продления требуется новый первичный
отчёт либо независимое подтверждение текущим поддерживаемым списком; дата
скачивания старой статьи не продлевает срок.

## Срок на установленном сервере

`scripts/ru/expire_filter.py` удаляет истёкшие блоки только из установленной копии
combined.txt и её кэша. Остальные правила сохраняются, включая одинаковые правила
других источников. При изменении служба AdGuard останавливается, обе копии
заменяются, служба запускается и проверяется DNS. При ошибке восстанавливаются
прежние байты и права. Если срок не наступил, DNS не перезапускается.

Шаблоны: `templates/dns-blocklists-expiry.service` и `.timer`. Перед установкой
сверьте абсолютные пути, id фильтра, службу и порт. Скопируйте expire_filter.py
и recent_threats.py в `/opt/dns-blocklists-ru/scripts/` с владельцем root;
units — в `/etc/systemd/system/`. Затем `systemctl daemon-reload` и
`systemctl enable --now dns-blocklists-expiry.timer`.
Timer проверяет в 00:00 UTC (точность до минуты) и после загрузки сервера.

Проверка без изменения фильтра: вызов expire_filter.py с теми же `--source`
и `--cache`, плюс `--check --as-of 2026-12-09`. Опция будущей даты разрешена
только в проверочном режиме. Рабочий запуск использует дату UTC сервера.
Перед административной заменой фильтра остановите timer и дождитесь завершения
его service; после проверки нового файла включите timer.

Этот timer не скачивает новые угрозы и не заменяет обновление источников.
После снятия блока SHA256 установленного файла отличается от исходного выпуска;
служба пишет новый SHA256 в systemd journal. Для отката храните конфигурацию,
исходный фильтр и его кэш одним комплектом.
